# ブラックフライデー テンプレート1(澤井珈琲)

黒 × 金 × 赤。電球の看板、箱から飛び出す福袋、赤い大きな価格が軸のテンプレート。
1カラム560px。PC幅(1100px以上)で両脇に看板と売り場案内ボタンが出て、スマホは下部メニューになる。

## ファイルの役割

| ファイル | 中身 | 流用時 |
|---|---|---|
| `js/shop-data.js` | 店名・商品・価格・クーポン・文言・並び順 | 店ごとに書き換える |
| `css/theme-*.css` | 色と書体の変数 | 店ごとに複製して値を変える |
| `css/bf-core.css` | レイアウトと部品の形 | 共通 |
| `js/bf-core.js` | 組み立てと動き | 共通 |
| `index.html` | 読み込むだけの枠 | theme の読み込み先とタイトルを変える |

## 他店へ流用する手順

1. このフォルダを `店名-blackfriday-2026` として複製する
2. `css/theme-sawai.css` を複製して店の配色にし、`index.html` の読み込み先を変える
3. `js/shop-data.js` の商品・文言を差し替える。`sections` の並びを変えて構成も変える
4. 同じ見た目にしないよう、下の「変える場所」から最低2つは変える

## 店ごとに変える場所

- 看板: 電球 → ネオン管(Yunth のネオン看板を流用可)
- 飛び出す物: 箱と福袋 → その店の象徴(枕、ハチミツの瓶、腕時計など)
- 配色: 黒×金 / 黒×ネオンピンク / 黒×シアン / 濃紺×銀
- キャッチ: 「黒いコーヒー屋の黒い祭り」は澤井専用。店ごとに考える
- `sections` の順番と、使う部品の組み合わせ

## 部品(`sections` に並べる名前)

| 名前 | 内容 |
|---|---|
| `schedule` | 第1弾〜第3弾の案内。開催中の弾が点灯する |
| `feature` | 各社の目玉商品枠。band の同額2点 + 大きい2点 |
| `deal` | 1商品を押す赤い枠。回転する放射線つき |
| `bargain` | お買い得枠。`more` で2段目も追加できる |
| `coupon` | まとめ買いクーポン + おすすめ商品 |
| `category` | カテゴリ別の売り場。店ごとに自由。季節ものもここ |
| `teaser` | 福袋が1つずつ点灯する本番予告。`mainLive: true` で商品一覧に切り替わる |

## 動き

ティッカー / 電球の点滅 / 看板の光 / 箱から飛び出す演出 / 数字がそろう演出 /
紙吹雪とコーヒー豆 / スポットライト / ボタンの光。
端末の「視差効果を減らす」設定では止まる。

## 楽天ブラックフライデーの日時

開催日時は本文にもソースにも書かない。カウントダウンは店舗独自の施策の日時だけを使う。
本番が始まったら `shop-data.js` の `mainLive` を手動で `true` にし、`teaser.bags` に商品を入れる。

## 納品前

- `isDemo: false` にする
- `coupon.isSample: false` にして、`tiers` にクーポンURLを入れる
- `index.html` の noindex を外す
- 確認用に日時を変えて見るときは `?now=2026-11-13T10:00` を付ける
